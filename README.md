# Generative AI Assignments

This repository contains Jupyter Notebooks covering foundational Generative AI, Natural Language Processing, and vector space concepts.

---

## 📚 Notebooks Overview

### 1. `Cosine_Similarity_Mathematically.ipynb`
- **Topic:** Cosine Similarity & Vector Mathematics
- **Description:** Mathematical understanding, formulas, and step-by-step calculations of cosine similarity between text vectors to measure semantic similarity.

### 2. `HuggingFace_Embeddings_Scratch_to_Intermediate.ipynb`
- **Topic:** Hugging Face Transformer Embeddings
- **Description:** Practical guide to generating and working with state-of-the-art transformer embeddings using Hugging Face libraries, from foundational concepts to intermediate implementations.

### 3. `word_embeddings.ipynb`
- **Topic:** Word Embeddings
- **Description:** Exploration of word vector representations, capturing syntactic and semantic relationships in vector spaces.

### 4. `Intro_to_Vector_Databases_ChromaDB.ipynb`
- **Topic:** Vector Databases & ChromaDB
- **Description:** Introduction to vector stores, indexing and managing embeddings, and querying semantic similarity with ChromaDB.

---

## 🚀 Getting Started

To run these notebooks locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/Niharika212006/GEN-AI-Assignment-.git
   cd GEN-AI-Assignment-
   ```

2. Set up a virtual environment and install dependencies:
   ```bash
   pip install notebook numpy scikit-learn transformers sentence-transformers chromadb
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
